# خطة التنفيذ: نظام الألوان البيج

## نظرة عامة

تهدف هذه الخطة إلى تحويل نظام الألوان الحالي للموقع من النظام الداكن البنفسجي إلى نظام ألوان جديد يعتمد على اللون البيج كلون أساسي. سيتم التنفيذ من خلال تحديث متغيرات CSS الجذرية وضمان التوافق البصري والوضوح في جميع عناصر الواجهة.

## المهام

- [-] 1. إعداد نظام الألوان الأساسي الجديد
  - تحديث متغيرات CSS الجذرية في `:root` بألوان البيج الجديدة
  - تعريف مجموعة ألوان البيج الكاملة (فاتح جداً، فاتح، متوسط، داكن، داكن جداً)
  - إنشاء ألوان الحالات الجديدة (نجاح، تحذير، خطأ، معلومات)
  - تحديث ألوان الخلفيات والحدود والظلال
  - _المتطلبات: 1.1، 1.2، 1.4_

- [ ]* 1.1 كتابة اختبار خاصية للتباين الشامل للألوان
  - **الخاصية 1: تباين الألوان الشامل**
  - **تتحقق من: المتطلبات 2.2، 2.4، 3.5، 4.1، 7.1**

- [ ] 2. تحديث مكونات واجهة المستخدم الأساسية
  - [ ] 2.1 تحديث ألوان الأزرار والعناصر التفاعلية
    - تطبيق الألوان الجديدة على `.btn-primary`، `.btn-outline`، `.btn-success`، `.btn-danger`
    - تحديث تأثيرات hover وactive للأزرار
    - ضمان وضوح النصوص على الأزرار الجديدة
    - _المتطلبات: 2.1، 2.2، 2.5_

  - [ ]* 2.2 كتابة اختبارات وحدة للأزرار التفاعلية
    - اختبار حالات hover وactive وdisabled
    - التحقق من تطبيق الألوان الصحيحة
    - _المتطلبات: 2.1، 2.5_

  - [ ] 2.3 تحديث ألوان البطاقات والحاويات
    - تطبيق الألوان الجديدة على `.card`، `.stat-card`، `.child-card`
    - تحديث خلفيات البطاقات والحدود
    - تعديل تأثيرات الظلال والتدرجات
    - _المتطلبات: 3.1، 3.2، 3.4_

  - [ ] 2.4 تحديث ألوان شريط التنقل
    - تطبيق الألوان الجديدة على `.navbar`، `.nav-brand`، `.nav-links`
    - تحديث ألوان الروابط وتأثيرات hover
    - ضمان وضوح العناصر مع الخلفية الجديدة
    - _المتطلبات: 2.1، 2.3_

- [ ] 3. نقطة تفتيش - التحقق من المكونات الأساسية
  - التأكد من تطبيق الألوان الجديدة بشكل صحيح على جميع المكونات الأساسية
  - فحص التباين والوضوح البصري
  - التأكد من عمل جميع الاختبارات، اسأل المستخدم إذا كانت هناك أسئلة

- [ ] 4. تحديث ألوان النصوص والمحتوى
  - [ ] 4.1 تحديث ألوان النصوص الأساسية
    - تطبيق الألوان الجديدة على `--text-primary`، `--text-secondary`، `--text-muted`
    - ضمان تباين كافي مع الخلفيات الجديدة
    - تحديث ألوان العناوين والفقرات
    - _المتطلبات: 4.1، 4.2، 4.5_

  - [ ]* 4.2 كتابة اختبار خاصية لمعايير إمكانية الوصول
    - **الخاصية 2: معايير إمكانية الوصول الشاملة**
    - **تتحقق من: المتطلبات 4.4، 7.2**

  - [ ] 4.3 تحديث ألوان الأيقونات والرموز
    - تطبيق الألوان الجديدة على جميع الأيقونات
    - تحديث ألوان أيقونات الحالة والتنبيهات
    - ضمان وضوح الأيقونات مع الخلفيات الجديدة
    - _المتطلبات: 4.3_

- [ ] 5. تحديث الشارات والمؤشرات البصرية
  - [ ] 5.1 تحديث ألوان الشارات (Badges)
    - تطبيق الألوان الجديدة على `.badge-normal`، `.badge-attention`، `.badge-hyperactive`، `.badge-autism`
    - الحفاظ على المعنى البصري للألوان (أخضر للطبيعي، أحمر للتحذير)
    - ضمان وضوح النصوص داخل الشارات
    - _المتطلبات: 5.3، 5.5_

  - [ ]* 5.2 كتابة اختبار خاصية لوضوح المؤشرات البصرية
    - **الخاصية 3: وضوح المؤشرات البصرية**
    - **تتحقق من: المتطلبات 5.3**

  - [ ] 5.3 تحديث ألوان الرسوم البيانية
    - تطبيق الألوان الجديدة على عناصر الرسوم البيانية
    - تحديث ألوان المؤشرات في صفحة النتائج
    - ضمان التمايز بين الفئات المختلفة
    - _المتطلبات: 5.1، 5.2، 5.4_

- [ ] 6. تحديث صفحات خاصة ومكونات متقدمة
  - [ ] 6.1 تحديث ألوان صفحات المصادقة
    - تطبيق الألوان الجديدة على `.auth-card`، `.auth-logo`
    - تحديث ألوان النماذج والحقول
    - ضمان وضوح عناصر تسجيل الدخول والتسجيل
    - _المتطلبات: 1.3، 2.4_

  - [ ] 6.2 تحديث ألوان صفحة الكاميرا
    - تطبيق الألوان الجديدة على `.camera-wrap`، `.camera-indicator`
    - تحديث ألوان المؤشرات المباشرة والمقاييس
    - تحديث ألوان نتائج التحليل
    - _المتطلبات: 1.3، 5.1_

  - [ ] 6.3 تحديث ألوان النماذج والتفاعلات
    - تطبيق الألوان الجديدة على `.form-control`، `.scale-btn`
    - تحديث ألوان حالات focus وhover للنماذج
    - ضمان وضوح النصوص والتسميات
    - _المتطلبات: 2.1، 2.2، 4.1_

- [ ]* 6.4 كتابة اختبارات تكامل للصفحات الخاصة
  - اختبار التوافق عبر المتصفحات المختلفة
  - فحص الاستجابة على أحجام شاشة مختلفة
  - _المتطلبات: 6.1، 6.2، 6.3_

- [ ] 7. نقطة تفتيش - اختبار شامل للنظام
  - فحص جميع الصفحات للتأكد من تطبيق الألوان الجديدة
  - اختبار التباين وإمكانية الوصول
  - التحقق من التناسق البصري عبر الموقع
  - التأكد من عمل جميع الاختبارات، اسأل المستخدم إذا كانت هناك أسئلة

- [ ] 8. تحسينات الأداء والتوافق
  - [ ] 8.1 إضافة قيم احتياطية للمتصفحات القديمة
    - إضافة ألوان احتياطية لكل متغير CSS
    - ضمان التوافق مع المتصفحات التي لا تدعم متغيرات CSS
    - _المتطلبات: 6.1، 6.4_

  - [ ] 8.2 تحسين الأداء والتحميل
    - تحسين ترتيب تحميل الألوان
    - ضمان عدم وجود وميض أثناء تحميل الألوان الجديدة
    - _المتطلبات: 6.4_

  - [ ]* 8.3 كتابة اختبارات الأداء والتوافق
    - اختبار الأداء على أجهزة مختلفة
    - فحص التوافق مع قارئات الشاشة
    - _المتطلبات: 6.1، 6.4، 7.4_

- [ ] 9. التحقق النهائي والتوثيق
  - [ ] 9.1 مراجعة شاملة لجميع التغييرات
    - فحص جميع الصفحات والمكونات
    - التأكد من تطبيق جميع المتطلبات
    - إجراء اختبار نهائي للتباين وإمكانية الوصول
    - _المتطلبات: جميع المتطلبات_

  - [ ] 9.2 توثيق التغييرات والألوان الجديدة
    - توثيق جميع متغيرات الألوان الجديدة
    - إنشاء دليل استخدام للألوان الجديدة
    - توثيق أي تغييرات في السلوك أو التفاعل
    - _المتطلبات: جميع المتطلبات_

## ملاحظات

- المهام المميزة بـ `*` اختيارية ويمكن تخطيها للحصول على MVP أسرع
- كل مهمة تشير إلى متطلبات محددة لضمان التتبع
- نقاط التفتيش تضمن التحقق التدريجي من الجودة
- اختبارات الخصائص تتحقق من الخصائص الصحيحة الشاملة
- اختبارات الوحدة تتحقق من أمثلة محددة وحالات حدية
